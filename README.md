# LocalChat
A private web browser chat. You can host for free at any time. You and your friends privately! 

## Install fly.io
curl -L https://fly.io/install.sh | sh
export PATH="$HOME/.fly/bin:$PATH"

## Launch fly.io and create account
flyctl launch

## Deploy it
flyctl deploy --local-only

## To check logs (Optional)
flyctl logs
